Industrial design

The objects that furnish a room, from the tap to the vase. Each interior style has a net: for each category of objects, one industrial style, and for each object one form, material, finish and texture. Move a knob, and a category that the main style cannot hold moves to the first alternate that can.

Industrial styles

Each style gives eight signature objects, one for each category, and a range for each knob.

Data: data/industrial/ (vocabulary, styles and nets), checked by npm run validate. Previews: FLUX.2 [klein] 4B (Apache-2.0), rendered locally; they are generated images, not real products. Moodboard tiles: interior moodboards.
