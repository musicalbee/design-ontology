Objects

For each category of objects in the room, the net names one industrial style, and for each object one form, material, finish and texture. Move a knob, and a category that the main style cannot hold moves to the first alternate that can.

Moodboard tiles → objects

Select a tile to mark its objects in the net.

Data: data/industrial/ (vocabulary, styles and nets), checked by npm run validate. Moodboard tiles: FLUX.2 [klein] 4B (Apache-2.0), rendered locally; they are generated images, not real rooms. Industrial styles: the industrial design domain.
