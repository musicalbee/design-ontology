An open design ontology

One task. Every style that design has made of it.

Each style is a skill: a thesis, rules in numbers, tokens and a lineage. Each domain demo keeps one task still, the room, the front, the brand, and changes only the style. Then the difference that you see is the style.

Across the domains

The styles are not islands. A style has parents and children, it uses techniques, and people made it.

Lineage graphAll styles on one time line, with a lane for each domain and the edges between them. TechniquesThe methods that styles share, from halftone to long takes, and the styles that use each one. PeopleThe designers, artists and makers behind the styles.

The preview pictures are generated with an open image model (FLUX.2 [klein] 4B, Apache-2.0). They show what a style looks like. They are not real works, real places or real brands. Type specimens are drawn from open fonts, and print proofs are drawn by code from the rules of each process.
