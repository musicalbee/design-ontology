Demo kit

One set of parts for every page of the demo. A page gets the tip, the select and the person and org links with no edit, because nav.js loads the kit. The other parts are calls on window.Kit.

Tokens kit.css :root

The ground, the ink and one accent are the same as the top bar. Each kind of thing has its own colour, and so does each kind of edge between styles.

Style preview Kit.preview(id, { size })

Each preview is a 3:2 frame. A photograph fills the frame. A board (a specimen, a press proof, a swatch board, a logo lockup) sits whole on white, so that no part of it is cut. graph/kit.json gives the file and the fit for each of the 500 styles.

Chips Kit.style · person · org · material · process

One shape for the five kinds of thing. The media on the left says the kind: a preview for a style, a portrait for a person, an emblem for an org, a photo or a swatch for a material, a letter for a process. Hover or focus a chip to see its tip.

Canon tip automatic

The kit reads the href of each link on the page. A link to a style page, to a material or to a process gets the tip. A link to a person or an org gets the tip of faces.js or orgs.js. These are plain links, with no attribute:

Select automatic

Each <select> is as wide as its chosen option. Pick a long option to see the box grow.

Table Kit.table(el, { columns, rows, facet })

Sort on each column head (a second click turns the order). The filter box looks in each column, and the facet narrows to one domain. A page table that is plain HTML gets the same with Kit.sortable(table).

Time line Kit.timeline(el, items)

One lane for each style, a bar for its period, a dot for each milestone of its people. Here: Bauhaus and every style one hop away from it.

Echoes Kit.echoes(el, id)

Kin across domains: the styles that share a look with this one, one column for each domain.

Graph cloud Kit.cloud(el, id, { hops })

The neighbourhood of one style, ring by ring. The first ring is one hop away, the second ring two hops. Hover a node to light its edges. Click a node to put it in the centre; Ctrl or ⌘ + click opens its page.

Multi-hop paths Kit.paths(el, from, to) · Kit.pathFinder(el)

The shortest routes between two things over the whole ontology: styles, people, orgs, materials and processes. Each hop says what the edge is.
