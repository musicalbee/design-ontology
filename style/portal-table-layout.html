Portal Table Layout

internet · 1997–2006 · also: Web portal, Table layout, Directory page

A dense start page in HTML tables: a search box, a link directory, news boxes, banner ads and a blue and orange palette. Web portals of the late 1990s used it to keep a user on one site.

Core thesis

One page holds the whole web: pack every service, link and ad into a clear table of boxes.

Design principles

  • Build the page with nested HTML tables at 760px to 800px wide, centred, with 1px to 2px cell spacing.
  • Place the logo and a search box with a button in a header row of 60px to 80px, over a tab row of 24px.
  • Set a link directory in 2 or 3 columns of 11px to 12px text with bold category names.
  • Give each box a title bar of 18px to 22px in a light blue band (#99CCFF) with bold dark blue text.
  • Add a banner of 468px by 60px at the top and a skyscraper of 120px by 600px on the right.
  • Set all links in blue (#0000CC) with underline, and show the visited links in purple.
  • Use spacer images and a 1px line in grey (#999999) to hold the cell widths.

Anti-patterns

  • Large empty areas around content
  • One focal image and a short text
  • Hidden menus behind icons
  • Fluid, responsive layouts
  • Light, thin type at large sizes
  • Soft shadows and rounded cards

Palette

  • White #FFFFFF background
  • Pale Blue #99CCFF title band
  • Portal Blue #003399 heading
  • Link Blue #0000CC link
  • Orange #FF6600 accent
  • Light Grey #EEEEEE panel
  • Line Grey #999999 border
  • Ink #1A1A1A text
