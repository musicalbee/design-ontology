Brutalist Web (2014)

internet · 2014–now · also: Brutalist websites, Raw HTML web, Default-browser style

Browser-default type, blue underlined links, grey or white ground, no polish and visible structure. It came from the 2014 Brutalist Websites collection and answers the smooth, templated web.

Core thesis

A page is a document, not a product: show the raw structure and the web serves the reader without decoration.

Design principles

  • Use the browser default: black text on white (#FFFFFF) or grey (#C0C0C0), links #0000EE, visited links #551A8B, underlined.
  • Set body text in a default serif or a monospace at 16px with a 1.3 to 1.5 line height and a measure above 80 characters or full width.
  • Build the layout from plain blocks: tables, lists and rules of 1px to 2px; no more than 2 columns.
  • Use a single heading size jump of 2x: 16px body and 32px headings, in bold, no tracking.
  • Show structure: visible borders of 1px, a hard 2px rule between sections and raw URLs in text.
  • Make every interactive element a native control: default button, default input, default checkbox, 0 custom styling beyond a 1px border.
  • Use no more than 2 colours plus link blue, and no transitions.

Anti-patterns

  • Rounded corners, shadows and gradients
  • Custom web fonts beyond one monospace or serif
  • Hero sections with a stock photograph
  • Smooth scroll effects and entrance animations
  • Icon sets and illustration
  • Card layouts with equal tiles and padding above 24px
  • Cookie-cutter SaaS sections

Palette

  • White #FFFFFF background
  • Black #000000 text and rules
  • Link Blue #0000EE links and accent
  • Visited #551A8B visited links
  • Grey #C0C0C0 alternate surface
