AI Chat Interface

internet · 2022–now · also: Conversational UI, LLM chat UI, Prompt-first UI

A single centred column, one large input at the bottom, streaming text, suggestion chips and almost no chrome. It came with ChatGPT in 2022 and makes language the main control.

Core thesis

The interface is a conversation: one box to speak into, and everything else appears in the reply.

Design principles

  • Centre one column of 680px to 768px; use a measure of 60 to 75 characters and 16px to 17px text with a leading of 1.6.
  • Dock a single input at the bottom: height 56px to 120px that grows to 200px, radius 16px to 28px, with a send button of 32px to 40px inside it.
  • Mark user turns with a tinted bubble (radius 18px, max width 80%) and leave assistant turns as plain text with no bubble.
  • Stream text word by word at 20 to 60 words per second and show a 12px pulsing cursor or dot while it streams.
  • Offer 3 to 4 suggestion chips (height 36px to 44px, radius 999px) on the empty state and 2 to 3 follow-ups after a reply.
  • Hide the sidebar by default on screens under 768px and keep it 260px wide on desktop with one row per chat of 36px.
  • Show sources, tools and code as collapsible blocks with a 1px border and 12px radius; code blocks use a mono face at 13px.

Anti-patterns

  • Dashboards of tiles and many menus beside the chat
  • Heavy bubbles around every assistant message
  • Decorative backgrounds behind text
  • Multi-column layouts for the main reply
  • Dense toolbars above the input
  • Typing indicators that fake a human
  • Hidden input that needs a click to open

Palette

  • Page #FFFFFF background
  • Ink #1F1F23 text
  • Tint #F4F4F5 user bubble and input
  • Mute #6B6B76 secondary text
  • Accent #D97757 accent and cursor
  • Line #E4E4E7 border
