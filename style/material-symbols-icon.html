Material Symbols

icon · 2014–present · also: Material Icons, Google Material icon system

Google's open icon system: geometric glyphs on a 24 dp grid with keyline shapes. Material Icons (2014) gave five themes; Material Symbols (2022) is a variable font with axes for fill, weight, grade and optical size.

Core thesis

An icon system is a set of tokens: one grid and four variable axes let one glyph serve every size, weight and state.

Design principles

  • Draw on a 24 × 24 dp grid with a live area of 20 × 20 dp and 2 dp of padding.
  • Fit each glyph to a keyline: a circle of 20 dp, a square of 18 dp, a portrait rectangle of 16 × 20 dp or a landscape rectangle of 20 × 16 dp.
  • Set the stroke at 2 dp for weight 400, from 100 to 700 on the weight axis.
  • Use the fill axis (0 or 1) for state: outline for inactive, filled for active.
  • Set the optical size axis to the render size (20, 24, 40 or 48 dp).
  • Use a corner radius of 2 dp for the rounded style and 0 dp for the sharp style; the outlined style uses 0–1 dp.

Anti-patterns

  • Glyphs off the keyline shapes
  • Stroke weights that differ inside one screen
  • Decorative colour inside a system glyph
  • Perspective or 3D effects
  • Fill state changes without meaning
