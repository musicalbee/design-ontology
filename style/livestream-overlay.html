Livestream Overlay

internet · 2011–now · also: Stream overlay, Twitch layout, Streamer scene

A frame around a live game or camera. It has a facecam slot, a chat panel, an alert box and a name bar. Neon edges and animated panels show that the stream is live.

Core thesis

A live show needs a control room on screen: the frame holds every live signal in fixed slots, so the viewer always knows where to look.

Design principles

  • Divide the 1920x1080 frame into fixed slots: game 1440x810, facecam 360x270, chat 360x540 and a 1920x80 bar.
  • Frame each slot with a 2px line in the accent colour and cut corners at 45° for 12px.
  • Put a LIVE tag with a pulsing dot of 12px in the top-left corner at all times.
  • Set alert boxes at 480x120 with a 300ms slide-in and a 5s hold.
  • Show the latest follower, donation and subscriber in small mono labels of 14px to 18px.
  • Use a dark ground (#0E0E12) with one neon accent (#9146FF or #00F0A0) and a second colour for alerts only.
  • Keep the game slot free of overlays except the alert box and the LIVE tag.

Anti-patterns

  • Soft, quiet layouts with no slots
  • Full-bleed footage with no frame
  • Pastel palettes
  • Decorative scripts and serif faces
  • Static panels with no live signal
  • Alert boxes that cover the game centre

Palette

  • Control Black #0E0E12 background
  • Panel Slate #1A1A24 surface
  • Signal White #F4F4FA text
  • Stream Violet #9146FF primary
  • Alert Mint #00F0A0 accent
  • Live Red #FF3B4E highlight
