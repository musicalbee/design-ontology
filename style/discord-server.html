Discord Server

internet · 2015– · also: Chat server, Community server

A dark chat app for a community: a rail of round server icons, a list of text and voice channels, a stream of messages in time order with avatars, and emoji reactions under each message.

Core thesis

A community lives in a room that is always open, and the talk flows in real time instead of in threads.

Design principles

  • Use three columns: a rail of 72px with round server icons, a channel list of 240px, and the message stream.
  • Name text channels with a # and voice channels with a speaker icon.
  • Show each message group with a round avatar of 40px, a coloured user name, a time stamp and the text under it.
  • Put emoji reactions under a message as small pills with a count.
  • Use a dark grey ground with a blue-violet brand colour for the active items.
  • Give each role a colour and set the user name in that colour.

Anti-patterns

  • Light themes with white space
  • Threads as the main structure
  • Posts with titles and scores
  • Serif body text in the chat
  • Static pages with no presence

Palette

  • Channel Grey #2B2D31 panel
  • Chat Grey #313338 panel
  • Text White #F2F3F5 text
