Kaomoji and Emoticon

internet · 1986–now · also: Text emoticon, Western emoticon, Japanese kaomoji, ASCII face

A face made of punctuation and letters, set in a line of plain text. It came from 1980s bulletin boards: the sideways :-) in the West and the upright (^_^) in Japan.

Core thesis

A face needs no picture: a few characters of one text font, in one colour, carry a whole feeling.

Design principles

  • Build each face from 3 to 12 characters of the same monospace font, in one colour and one size.
  • Set the face on a plain ground of #FFFDF5 with text at #1A1A1A, with no border and no fill.
  • Keep the face inline with the text, on the same baseline, with 1 space before and after.
  • Use the upright Japanese form (^_^) for the eyes and mouth, and the sideways Western form :-) only for short chat lines.
  • Limit one message to 1 or 2 faces; repeat a character (^^^, !!!) up to 3 times for emphasis.
  • Set the body text in a 16px mono font at a line height of 1.6, and let the face take the same size.
  • Render the faces at an integer pixel size, with no anti-aliased scaling above 200%.

Anti-patterns

  • Coloured emoji pictures in place of characters
  • Faces that need a picture font to display
  • Gradients, shadows and glossy fills behind the face
  • More than 3 faces in one line
  • Proportional fonts that break the face alignment
  • Faces drawn at a size different from the text

Palette

  • Paper #FFFDF5 background
  • Ink #1A1A1A text and primary
  • Soft Grey #F2EFE3 surface
  • Pencil #5A5A55 muted text
  • Blush #E8506A accent for one face
  • Terminal Green #2E7D32 code line
